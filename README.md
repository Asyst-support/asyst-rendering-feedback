# ASysT Rendering — feedback & issue tracker

This is the public feedback tracker for **[ASysT Rendering](https://marketplace.visualstudio.com/items?itemName=juce.asyst-vscode)**,
a SysML v2 viewer & layouter for Visual Studio Code.

- 🐛 **Found a bug?** [Open a bug report »](../../issues/new?template=bug_report.yml)
- 💡 **Have an idea?** [Suggest a feature »](../../issues/new?template=feature_request.yml)
- 🔒 **Private matter** (licence, Enterprise, anything you'd rather not post)? Email
  **asyst.rendering@gmail.com**

Please [browse existing issues](../../issues) first — your report might already be there, and a 👍
on an existing one is the most useful vote.

## What makes a great bug report

- The **extension version** (Extensions view → ASysT Rendering) and your OS.
- Roughly how big the model is — the number of `.sysml` files is enough.
- What you did, what you expected, and what you saw — a screenshot helps a lot.
- If a diagram looks wrong: which view it is (definition, internal structure, state…).

Your model files are yours — never feel obliged to attach them. A screenshot or a minimal snippet
is plenty.
